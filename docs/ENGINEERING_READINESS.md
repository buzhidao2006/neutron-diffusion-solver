# 工程级验证准备度评估

**评估结论：尚不具备工程级物理验证资格。**本文件完成的是准备度评估，不是验证合格证明；项目仍仅用于教学。

## 具体预期用途与边界

选定假设性用途：以本程序预测**真实压水堆堆芯正常运行工况下的有效增殖因子 `k_eff`，作为设计审查的定量输入**。这比现有“一维均匀裸平板教学算例”要求高得多。本评估不批准这种用途，也不涉及事故分析或运行安全决策。实际容许偏差、工况包络及安全裕度需由具备资质的使用方定义，当前尚无可批准的数值验收标准。

## 缺口清单

| 方面 | 当前已有 | 对选定用途的关键缺口 |
| --- | --- | --- |
| 物理模型 | 一维/二维/三维简化双群扩散、教学燃耗耦合 | 真实堆芯组件/反射层/控制棒的非均匀几何、群常数生成与谱效应、温度/密度/硼反馈、泄漏和燃耗历史；需明确扩散近似适用范围。 |
| 可信数据 | 硬编码教学截面；无材料溯源 | 可追溯的评价核数据库、处理流程、温度和燃耗依赖的群常数、制造公差、协方差及配置管理。 |
| 实验验证范围 | 均匀裸平板解析基准及现有软件测试 | 用途相关、覆盖目标工况包络的公开或受控临界实验和运行测量矩阵；记录测量误差、实验配置、材料与几何差异。独立代码比对可辅助，但不能替代实验验证。 |
| 不确定度与偏差 | 网格收敛和部分步长/守恒回归测试 | 截面、几何、边界、模型形式、离散和迭代误差的敏感性与不确定度传播；基准偏差、趋势、相关性、外推风险以及与用途相关的验收界限。 |
| 质量保证与独立审查 | 自动测试、Ruff、CI、可复现的部分导出 | 需求—测试可追溯、版本冻结、独立复算、审查记录、数据和配置审核、变更控制、失败工况与用户培训。 |

## 阶段门槛

1. 由预期使用机构写定工况、输出、允许误差和决策方式，并证明所选模型覆盖该范围。
2. 建立受控且有溯源的核数据与计算链；完成更广的数值解验证和收敛/守恒检查。
3. 对代表性的实验基准和运行测量完成输入重建、偏差评估及适用性分析；量化相关不确定度和外推限制。
4. 由独立于实现者的合格人员审查需求、模型、数据、基准、结果、异常与配置。只有全部要求针对**该用途**满足，才可讨论工程级验证结论。

目前第 1–4 项均未达到。`docs/RESEARCH_BENCHMARK.md` 的理想平板对比属于数值解核对，不提供真实堆芯的实验确认或可用于设计审查的误差范围。

## 依据

- [IAEA GSR Part 4 (Rev. 1)](https://www.iaea.org/publications/10884/safety-assessment-for-facilities-and-activities)：安全评价工具应核实、验证并考虑不确定度和用途适用性。
- [IAEA SSG-2 (Rev. 1)](https://www.iaea.org/publications/13428/deterministic-safety-analysis-for-nuclear-power-plants)：讨论模型与代码验证、适用的实验基准、敏感性/不确定度以及独立审查。
- [OECD NEA IRPhE](https://www.oecd-nea.org/jcms/pl_20279/irphe-handbook)：提供反应堆物理实验基准目录，可作为后续筛选用途相关实验案例的起点；本次**未**使用其受限数据作对比。
