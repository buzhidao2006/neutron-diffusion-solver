# 均匀双群裸平板基准对比

此记录是**研究级解析基准对比**，用于检查一维双群扩散求解器的实现与网格收敛；不是与实验测量的比较，更不是工程级物理验证。

## 来源与适用范围

R. E. Pevey, *Benchmarking Report for WIGGLE*, DOE/OSTI 6398033 (1990)，给出均匀双群裸平板扩散问题的正弦基模解析构造：[公开报告](https://www.osti.gov/servlets/purl/6398033)。本项目取该公开问题的方程和边界形式，但采用自身的**教学示例系数**，没有声称复现原报告的具体材料工况或实验数据。适用对象仅为均匀、无反射层、一维、定常双群模型。

边界条件为零通量：`φ(0)=φ(L)=0`。`L=200 cm` 是从 `x=0` 到 `x=L` 的**全厚度**，不是半厚度。内部节点数为 `N`，间距 `h=L/(N+1)`。

## 输入与参考解

| 量 | 值 |
| --- | ---: |
| `D1`, `D2` | 1.2、0.4 cm |
| `Sa1`, `Sa2` | 0.008、0.08 cm⁻¹ |
| `Ss12` | 0.020 cm⁻¹ |
| `nu_Sf1`, `nu_Sf2` | 0.003、0.105 cm⁻¹ |
| `L` | 200 cm |
| 节点数 `N` | 20、40、80、160 |
| 迭代上限、相对容差 | 1000、1e-11 |

正弦基模的连续曲率为 `B²=(π/L)²`。由两群方程消元得到

```text
k = [nu_Sf1 + nu_Sf2 × Ss12 / (D2 × B² + Sa2)]
    / [D1 × B² + Sa1 + Ss12]
```

连续参考值为 `k=1.032568712`。离散参考值以有限差分特征值 `B_h²=4 sin²[π/(2(N+1))]/h²` 代入同一表达式；它独立于幂迭代，却共享离散方程。通量仅比较归一化形状，避免把任意的特征向量幅值当成误差。

## 结果

运行 `python -m benchmarks.slab_two_group`（代码：`benchmarks/slab_two_group.py`）：

| N | 数值 `k` | 离散参考 `k` | 相对连续误差 | 通量形状 L2 相对误差 |
| ---: | ---: | ---: | ---: | ---: |
| 20 | 1.032590975 | 1.032590975 | 2.156e-05 | 4.749e-09 |
| 40 | 1.032574555 | 1.032574555 | 5.659e-06 | 4.941e-09 |
| 80 | 1.032570209 | 1.032570209 | 1.450e-06 | 4.656e-09 |
| 160 | 1.032569090 | 1.032569091 | 3.670e-07 | 4.585e-09 |

每次约加密一倍，连续解误差约下降四倍，符合二阶中心差分的预期。数值结果与离散参考吻合，说明这一理想问题的离散组装和特征值迭代基本一致。自动检查见 `tests/test_benchmarks.py`。

## 局限

这只验证一个理想化方程在选定参数下的数值解，**不能**证明截面、几何或物理模型能预测真实堆芯。系数没有实验溯源或不确定度；没有非均匀材料、反射层、控制棒、温度反馈、三维效应、能谱细化或燃耗实验数据。更广的网格、参数和独立实现对比仍应补充；工程用途必须另行建立用途相关的实验验证与不确定度论证。
