# 均匀双群裸平板基准对比

此记录是**研究级解析基准对比**，用于检查一维双群扩散求解器的实现与网格收敛；不是与实验测量的比较，更不是工程级物理验证。

## 来源与适用范围

R. E. Pevey, *Benchmarking Report for WIGGLE*, DOE/OSTI 6398033 (1990)，给出均匀双群裸平板扩散问题的正弦基模解析构造：[公开报告](https://www.osti.gov/servlets/purl/6398033)。本项目取该公开问题的方程和边界形式，但采用自身的**教学示例系数**，没有声称复现原报告的具体材料工况或实验数据。适用对象仅为均匀、无反射层、一维、定常双群模型。

边界条件为零通量：`φ(0)=φ(L)=0`。`L=200 cm` 是从 `x=0` 到 `x=L` 的**全厚度**，不是半厚度。内部节点数为 `N`，间距 `h=L/(N+1)`。

## 输入与参考解

| 量 | 值 |
| --- | ---: |
| `D1`, `D2` | 1.2、0.4 cm |
| `Sa1`, `Sa2` | 0.008、0.08 cm⁻¹ |
| `Ss12` | 0.020 cm⁻¹ |
| `nu_Sf1`, `nu_Sf2` | 0.003、0.105 cm⁻¹ |
| `L` | 200 cm |
| 节点数 `N` | 20、40、80、160（每组参数均使用） |
| 迭代上限、相对容差 | 1000、1e-11 |

正弦基模的连续曲率为 `B²=(π/L)²`。由两群方程消元得到

```text
k = [nu_Sf1 + nu_Sf2 × Ss12 / (D2 × B² + Sa2)]
    / [D1 × B² + Sa1 + Ss12]
```

连续参考值为 `k=1.032568712`。离散参考值以有限差分特征值 `B_h²=4 sin²[π/(2(N+1))]/h²` 代入同一表达式；它独立于幂迭代，却共享离散方程。通量仅比较归一化形状，避免把任意的特征向量幅值当成误差。

另以**单独组装的两群有限差分矩阵**求解广义特征值问题 `Fv=kAv`，使用 SciPy 的稠密特征值求解器，而非项目的幂迭代或正弦模公式。这是同一简化方程的独立数值实现交叉核对，不是独立物理模型或实验验证。为增加参数覆盖，保持默认输入不变并额外设置两组教学扰动；表中未列参数均沿用上述默认值：

| 算例 | 全厚度 `L` | 相对默认值的截面改动 | 连续参考 `k` |
| --- | ---: | --- | ---: |
| 默认 | 200 cm | 无 | 1.032568712 |
| 较高热群吸收 | 160 cm | `Sa2=0.10 cm⁻¹` | 0.842074634 |
| 较强群间散射 | 240 cm | `D1=1.5 cm`，`D2=0.5 cm`，`Ss12=0.030 cm⁻¹`，`nu_Sf2=0.12 cm⁻¹` | 1.253413333 |

## 局限

这些比较只验证一个理想化方程在三组选定参数下的数值解，**不能**证明截面、几何或物理模型能预测真实堆芯。系数没有实验溯源或不确定度；没有非均匀材料、反射层、控制棒、温度反馈、三维效应、能谱细化或燃耗实验数据。稠密矩阵解只适合此处的小网格交叉核对；更广的参数范围及实际工况必须另行论证，工程用途仍需用途相关的实验验证与不确定度分析。
